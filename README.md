# Series Sector (Expo starter)

This project was reconstructed from the provided TXT export and completed with minimal missing routes/data files.

## Run
1. Install Node.js on a computer or use a browser-based development environment that supports Expo.
2. Run `npm install`.
3. Run `npx expo start`.

The project is a starter UI, not a production streaming service. The catalogue uses sample metadata and remote demo images. Authentication, licensed video playback, backend, real downloads, analytics, and store compliance are not implemented.

## Important
The source export did not include all referenced files. Missing routes, `types.ts`, and `data/seriesData.ts` have been added so the starter structure is more complete. Review and test before release.
